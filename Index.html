⌚ Apple Watch Bridge Setup

1
On your iPhone, open the Shortcuts app and create a new Automation: When Heart Rate rises above X (or on a repeating timer).
2
Add a Get My Heart Rate action to read the current value from HealthKit.
3
Add a Get Contents of URL action. Set method to POST, URL to your Frida deployment URL + /fdp (e.g. https://your-frida.netlify.app/fdp). Set body type to JSON.
4
Set the JSON body to:
{"device":"apple_watch","metric":"hr","value": [Shortcut Variable: Heart Rate], "timestamp": [Shortcut Variable: Current Date]}
5
Run the Shortcut manually once to test. Frida's FDP log will show the incoming reading. After confirming, set the automation to run every 1–5 minutes.
6
Alternative (no server): Tap Demo Mode on the Bio dashboard to simulate live data right now, or manually POST to Frida's window.FDP.ingest() from any automation tool.
